A program that sums up Wednesday 18 November 2026 world news in one image: Trump, Xi and Putin meet in Shenzhen, US strikes Iran in Hormuz, Cyclone Akvan, Gaza, Nvidia and the Alaska Senate flip. Pure Python standard library only, it draws a 1024x1024 newspaper front page and writes it to /output/entry.png, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
